# Issue #76: Admin Status Dropdown Colors

**Goal:**
Change the background and text color of the application status dropdown in the admin Bookings table to match the selected status (e.g., yellow for pending, green for approved), improving visual scanning.

**Requirements:**
1. Identify the CSS class used for the dropdown (`.admin-status-dropdown`).
2. Add specific CSS rules for `.admin-status-dropdown` combined with status classes (`.pending`, `.approved`, etc.) to override the default gray styling.
3. Ensure the border color also matches the status color for a cohesive look.
